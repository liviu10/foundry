# Crypt

> AES-256-GCM authenticated encryption with key rotation support and HMAC validation.

Canonical: https://foundry.insightdevhub.ro/docs/crypt/  
Namespace: `Foundry\Crypt` · File: `Crypt.php` · Version 1.1 · PHP 8.3+ · Extensions: openssl

Authenticated encryption using AES-256-GCM (openssl) and HMAC-SHA256.

GCM detects any modification to the ciphertext: altered text, an incorrect key, or a mismatched context throws an exception during decryption rather than returning corrupted data.

## Key

- 32 random bytes, stored as base64 (e.g. in .env: APP_KEY=base64:...)
- generated once using Crypt::generateKey()
- NO default key: a missing or short key throws an exception.

Context (optional) binds ciphertext to its intended purpose: an IBAN encrypted with context 'iban' cannot be decrypted with context 'cnp' (e.g. if moved to another column).

Key rotation: decrypt() accepts a list of keys (newest key first, followed by previous keys).

Format: base64url( version(1) | iv(12) | tag(16) | ciphertext ).

## Usage

```php
require_once 'Crypt.php';
use Foundry\Crypt;

$key = Crypt::generateKey();                         // generated once; saved in .env

$stored = Crypt::encrypt($iban, Env::string('APP_KEY'), context: 'client.iban');
$iban = Crypt::decrypt($stored, Env::string('APP_KEY'), context: 'client.iban');

$iban = Crypt::decrypt($stored, [Env::string('APP_KEY'), Env::string('APP_KEY_OLD')], 'client.iban');

$signature = Crypt::hmac($payload, $secret);
if (! Crypt::verifyHmac($payload, $receivedSignature, $secret)) { ... }
```

## Methods

### generateKey()

```php
public static function generateKey(): string
```

Generates a new key formatted as "base64:...". Keep this secret (e.g. in .env).

Returns `string`.

### encrypt()

```php
public static function encrypt(string $plaintext, string $key, string $context = ''): string
```

Encrypts plaintext.

Parameters:
- `$plaintext` (`string`, required): Data to encrypt (binary-safe).
- `$key` (`string`, required): Key as base64 string (with or without "base64:" prefix).
- `$context` (`string`, default `''`): Purpose of data (optional); must match identically during decryption.

Returns `string`: Safe for URLs, JSON, and databases (base64url).

Throws:
- `InvalidArgumentException`: If the key is invalid.
- `RuntimeException`: If encryption fails.

### decrypt()

```php
public static function decrypt(string $payload, string|array $keys, string $context = ''): string
```

Decrypts a payload generated by encrypt().

Parameters:
- `$payload` (`string`, required): Encrypted payload string.
- `$keys` (`string|list<string>`, required): Key or list of keys tried in order (key rotation).
- `$context` (`string`, default `''`): Same context as used during encryption.

Returns `string`.

Throws:
- `InvalidArgumentException`: If a key is invalid.
- `UnexpectedValueException`: If data is tampered with, or key/context does not match.

### hmac()

```php
public static function hmac(string $data, string $secret): string
```

Generates HMAC-SHA256 as lowercase hexadecimal string (64 characters). For signing webhooks, URLs, etc.

Parameters:
- `$data` (`string`, required)
- `$secret` (`string`, required)

Returns `string`.

Throws:
- `InvalidArgumentException`: If the secret has fewer than 32 bytes.

### verifyHmac()

```php
public static function verifyHmac(string $data, string $mac, string $secret): bool
```

Verifies an HMAC-SHA256 in constant time (preventing timing attacks).

Parameters:
- `$data` (`string`, required)
- `$mac` (`string`, required)
- `$secret` (`string`, required)

Returns `bool`.

Throws:
- `InvalidArgumentException`: If the secret has fewer than 32 bytes.
