Why Foundry

Zero dependencies

100% native PHP. Composer is a development tool for the library, never a runtime requirement for your project.

One file, one tool

Every class is a single file with no links to other files. Copy Json.php on its own and it works.

Explicit errors

Failures throw standard SPL exceptions that name the operation, the context and the root cause. Native warnings are converted, never leaked.

No personal data in errors

Exception messages report lengths, types and paths, never the payload. Logs and dumps mask passwords, tokens, CNP and IBAN values.

The difference, in one line

Native PHP functions often return false or null and emit a warning. Foundry turns every one of those cases into an exception you can catch, log and fix.

Native PHP
// Native PHP: silent failure
$data = json_decode('{"a":1,}', true);

var_dump($data);
// NULL - was the input "null", or broken?
Foundry
// Foundry: explicit exception
$data = Json::decode('{"a":1,}');

// JsonException: Json::decode():
// Syntax error (input length: 8 bytes).
